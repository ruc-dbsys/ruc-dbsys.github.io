教学

从 1978 年萨师煊先生在人大开设中国第一门数据库课程算起，至今已 48 载、四代薪传。我们始终把人才培养放在与科研同等重要的位置；近年，面向国家数据库技术自主可控的迫切需求，团队牵头推动从「用数据库」到「造数据库」的课程改革。

「101 计划」数据库系统课程建设 — 牵头单位

2022 年起，杜小勇教授牵头、卢卫教授具体运营教育部「101 计划」数据库系统课程虚拟教研室，由中国人民大学联合北京大学、清华大学等 13 所高校共建。面向本科生「造数据库」人才培养的核心诉求，我们完成了三件事：

  • 重构课程知识体系：调研国内外 124 所高校、207 门课程，提炼 5 大核心知识模块、68–77 个知识点的课程知识图谱，并为每一点撰写教案；相关成果已刊于《高等学校人工智能专业人才培养战略研究报告暨核心课程体系》。
  • 配套教材与实验平台：主编「101 计划」计算机核心教材《数据库管理系统原理与实现》（清华大学出版社，2024）；研制教学型数据库原型 RUCBase（「麻雀虽小、五脏俱全」，代码 ≈ 2 万行，开源 ruc-deke/rucbase-lab ↗）。
  • 办大赛、办导教班：首创并承担全国大学生计算机系统能力大赛·数据库赛道（2023—2025 连办三届，累计 1000+ 支队伍、2600+ 名本科生参赛；基于 RUCBase / RMDB、以 TPC-C 为基准）；连续三年在龙岩、天津、眉山举办「101 计划」数据库系统课程导教班，助力 120+ 位教师掌握「造数据库」课程讲授方法。

推广情况：RUCBase 已在中国人民大学、哈尔滨工业大学、华中科技大学、西安电子科技大学、山西大学、温州大学、湖南大学等多所高校使用。

《数据库系统概论》 — 国家级一流本科课程

本课程由萨师煊先生开创、王珊先生和杜小勇教授接续发展，2020 年同时获评「国家级线上线下混合式一流本科课程」与「国家级线上一流本科课程」。

  • MOOC：与团队一同在中国大学 MOOC 平台持续建设《数据库系统概论》基础篇、应用篇、新技术篇三门线上课程；截至当前已开设 50 期、服务学员 63 万人次；疫情期间支撑 162 所高校的混合教学。2024 年完成最新一轮更新，新增教学视频 17 个。
  • SQL 在线实验平台（sql.ruc.edu.cn ↗）：面向作业部署、学习行为数据采集与个性化教学。曾获「全国计算机类课程实验教学案例设计竞赛」一等奖。
  • 混合式教学改革（2017 起）：率先提出「授业 - 解惑 - 传道」三位一体教学体系——知识图谱驱动的结构化讲授、基于 SQL 平台数据的个性化答疑、以真实问题驱动的项目闭环（如「实验室预约系统」「学生第二课堂管理」等已上线使用）。
  • 课程思政与立德树人：入选北京市课程思政教学团队；在绪论中讲述萨师煊、王珊等我国数据库奠基人的奋斗历程，激励学生科技报国、弘扬工匠精神。

其他课程与资源

  • 数据库系统实现（图灵班） — 面向本科拔尖人才，内核实现、并发控制、查询处理的实践课（配合 RUCBase / RUC Transaction Tester / MiniOB）。
  • 高级数据库系统 — 面向研究生，内容涵盖查询优化、分布式事务、新型数据库架构。
  • 大模型原理与应用 — 面向本科高年级与研究生，涵盖 Transformer、Scaling Law、对齐（RLHF/DPO）、Agent 等。
  • 教学型数据库 RUCBase — 配套「完形填空 → 自动测试 → 性能调优」渐进式工程训练链，持续迭代，面向国内高校开放使用。
RUCBase 贯穿了数据库底层实现中的存储、索引、查询、并发等各个方面，经过一学期的学习，不仅进一步了解了 Linux 底层的存储交互、复习了编译原理的实现细节，还掌握了 B+ 树、并发锁等数据库基础知识。 ——— 选课学生课程总结
